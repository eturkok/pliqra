# Pliqra 2.1.0-rc.4

A responsive console for desktop, tablet and phone screens, including compact laptop windows.

## Improvements

- The sidebar keeps its brand/workspace and profile visible while the navigation scrolls independently. Tablet and phone navigation has an explicit close action, backdrop, contained keyboard focus and Escape/focus return.
- Small-screen tables become labelled cards. Every field remains available; wide desktop tables retain their own keyboard-accessible scrolling area. Filters have consistent panel spacing and stack on narrow screens.
- Page actions, metric cards, workflow tabs, quota/guardrail editors and long identifiers adapt to the available width. Phone inputs use readable sizes and touch targets.
- Dialogs and request drawers keep their headers and actions reachable while their bodies scroll within the available viewport height. Form errors scroll into view, request drawers restore focus, and login preserves the requested page.
- Shared action buttons have explicit button types, so filter and editor actions do not accidentally submit their enclosing forms.

- **Reliable SDK retries:** an already published SDK completes successfully only after public files match the tested release hashes. Different bytes, incomplete releases and registry access errors stop the workflow.

## Validation

102 main-page/viewport combinations across 320–1440 px widths, 12 narrow-screen sub-tabs, 23 form/viewport combinations, three login sizes and three drawer sizes were exercised in the in-app browser. Keyboard containment/return, visible validation errors, filter application and login deep links also passed. These are controlled browser viewport checks with synthetic data; physical iOS/Android and cross-engine certification are outside this record.

[UI validation and screenshots](https://github.com/eturkok/pliqra/blob/main/docs/RESPONSIVE_UI.md).

## Install

```sh
curl -fL -o compose.release.yaml https://github.com/eturkok/pliqra/releases/download/v2.1.0-rc.4/compose.release.yaml
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

Open **http://localhost:8088**. Schema **6**, inference contract **5**, protocol draft **0.1** and SDK candidate **0.1.0-rc.1** continue to apply. Back up before upgrading and use the normal [distribution procedure](https://github.com/eturkok/pliqra/blob/main/docs/DISTRIBUTION.md). The release remains a candidate for evaluation; the [RC3 acceptance boundaries](https://github.com/eturkok/pliqra/blob/main/docs/ACCEPTANCE.md) still apply.
