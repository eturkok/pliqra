# Pliqra 2.1.0

**Stable community release: bring a model endpoint, publish governed AI services, and connect applications through explicit contracts.**

## Included

- Model-as-a-service catalog, custom gateways, scoped access, request/token quotas, budgets, concurrency, composable local/NeMo/custom guardrails and detailed administrator visibility.
- Active/active gateways with one writable PostgreSQL authority, global admission, local routing, site controls and fail-closed recovery.
- Incremental Responses/Anthropic Messages text and tool streaming, plus the documented Chat, embedding, audio and Ollama interfaces.
- Independently paired fleet workspaces, reviewed policy proposals and delivery/drift visibility.
- Responsive charcoal/orange console, including phone navigation, readable table cards and usable dialogs.
- Packaged Python and JavaScript/TypeScript SDK **0.1.0**, clean-install compatibility checks and immutable OIDC publication.

## Release gates

The exact image must pass native AMD64/ARM64 smoke, automated Python/PostgreSQL/client tests, dependency-advisory audit, synthetic application/native-client acceptance, a **30-minute soak**, and **RC4 upgrade / encrypted-backup recovery** before this release becomes public. Reports, SDKs, image digest and checksums are attached. The [readiness review](https://github.com/eturkok/pliqra/blob/v2.1.0/docs/STABLE_2_1.md) describes each gate.

## Install

```sh
mkdir pliqra && cd pliqra
curl -fL -o compose.release.yaml https://github.com/eturkok/pliqra/releases/download/v2.1.0/compose.release.yaml
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

Open **http://localhost:8088**, create the administrator and connect your model endpoint. No source build or registry login is required. The workspace starts empty.

SDKs are independently versioned: `pip install pliqra-client==0.1.0` and `npm install @eturkok/pliqra@0.1.0` after registry delivery, or install the attached tested packages directly.

## Upgrade and scope

Schema **6** and inference contract **5** are unchanged from RC4. Preserve the data volume/master key, back up first, stop old replicas and upgrade every shared-state replica together. An unchanged RC4 application binding is checked across the upgrade. Recovery to the previous image uses the pre-upgrade backup in separate storage.

Stable covers the [documented self-hosted support envelope](https://github.com/eturkok/pliqra/blob/v2.1.0/docs/SUPPORT.md); it does not claim a production capacity or availability SLA. Protocol **0.1 remains a draft**, native APIs are documented subsets and actual vendor/geographic/customer acceptance remains installation-specific.
