# Pliqra 2.4.0-alpha.1 — scheduled behavior observations

Development source; no 2.4 release or prebuilt image has been published. Stable distribution remains 2.3.0. Protocol 1.0, legacy 0.1 and SDK 1.0.1 interfaces remain unchanged.

- Add opt-in model behavior schedules through the administrator console and API: chat/custom text, streaming completion, fixed JSON and tool assertions, with optional full-response latency expectations.
- Show latest outcomes, last successful tests, most recent changes, cycle history and failure/recovery notifications. Repeat failures do not repeat transition notifications.
- Bound execution with UTC daily cycle reservations, output-token and timeout limits, normal project budgets and shared concurrency. Pause stops subsequent checks after a started call finishes.
- Persist schedule/version/history across restarts; serialize claims across PostgreSQL replicas and respect site placement, draining, maintenance and replica fencing. Interrupted calls are not replayed.
- Observe without changing declared/verified capabilities, circuit state, application contracts or traffic policy. Encrypt test configuration at rest and retain no response text.

**Storage upgrade:** schema 6 → 7. Take and verify a database/key backup; coordinate all writers. Older schema-6 portable archives can restore into 7, with schedules paused after restore. A downgrade requires the pre-upgrade schema-6 backup.
