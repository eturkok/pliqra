# 2.3.0-alpha.1 — application impact and existing-client contracts

Development source for the 2.3 track. No release tag or prebuilt 2.3 image is published by this change. Stable downloads remain 2.2.2.

- Service previews and new gateway impact reports identify affected bindings, application identities, team/project attribution, accepted requirements, blockers and renewal actions.
- Console publication revalidates the reviewed service/policy fingerprint with optional `If-Match` conflict protection. Management API callers can use the same guard.
- Existing Chat Completions clients can use `X-Pliqra-Binding` on standard/named gateway JSON and streaming calls. Accepted requirements and current identity, expiry, contract, guardrail and quota checks apply.
- Unsupported interfaces and malformed headers fail explicitly. Binding identifiers never reach upstream models.
- Real local SmolLM2/llama.cpp acceptance exercises an installed official OpenAI client and the change/reconnect lifecycle. See [the guide and evidence](../CONTRACT_CHANGES.md).

Protocol 1.0, SDK 1.0.1, database schema 6 and inference contract 5 retain their lifecycle. Existing bindings and clients keep their accepted behavior. Reports assess declared configuration and observed readiness; external guardrail and model behavior require execution tests.
